\section{La neurona}

\begin{frame}
\begin{center}
    \includegraphics[scale=0.12]{img/neurona.jpg}
\end{center}

\begin{itemize}
    \item<1-> Las neuronas se comunican a través de impulsos (sinapsis).
    \item<2-> Una neurona recibe los impulsos de las neuronas precedentes en la red. Estos impulsos pueden ser excitatorios (+) o inhibitorios (-).
\end{itemize}
\end{frame}

\begin{frame}
\begin{center}
    \includegraphics[scale=0.12]{img/neurona.jpg}
\end{center}

\begin{itemize}
    \item<1-> Durante un corto periodo de tiempo, la neurona \textit{suma} los impulsos recibidos.
    \item<2-> La neurona dispara un impulso si la suma supera cierto umbral. 
\end{itemize}
\end{frame}

\begin{frame}
    \begin{columns}
        \begin{column}{0.5\textwidth}
            \includegraphics[width=\textwidth]{img/perceptron_simple.jpg}            
        \end{column}
        \begin{column}{0.5\textwidth}
            \begin{enumerate}
                \item<1-> La neurona recibe los impulsos de las neuronas precedentes y los suma:
                \[\sum_{i} w_ix_i\]
                \item<2-> Si la suma supera el umbral $b$, la neurona \textit{dispara}
                \[y = \begin{cases}
                    1 \qquad \text{si } \sum_{i} w_ix_i > b \\
                    0 \qquad \text{si no}
                \end{cases}\]
            \end{enumerate}
        \end{column}
    \end{columns}
\end{frame}

\begin{frame}
    \textbf{Obs:} 
    \[\sum_{i} w_ix_i > b \iff \sum_{i} w_ix_i -b > 0 \iff \sum_{i} w_ix_i +b\cdot(-1) > 0\]
    $\Rightarrow$ agregamos una neurona para el bias, la neurona se activa si el impulso que recibe es mayor que $0$

    \pause
    \vspace{1cm}
    Consideramos la siguiente función:
    \[f(t) = \begin{cases}
                    1 \qquad \text{si } t > 0 \\
                    0 \qquad \text{si no}
                \end{cases}\]
    Que será nuestra \textbf{función de activación}.
\end{frame}

\section{Entrenando a la Red Neuronal}

\begin{frame}
    Las redes neuronales tienen \textbf{muchísimas} aplicaciones:
    \begin{itemize}
        \item<1-> Clasificación
        \item<2-> Regresión
        \item<3-> Clustering
        \item<4-> Reducción de dimensionalidad
        \item<5-> Compresión (\textit{auto-encoders})
        \item<6-> Reconocimiento de patrones
        \item<7-> Y muchas más!
    \end{itemize}

    \only<7>{Vamos a centrarnos en \textbf{clasificación} y \textbf{regresión}.}
\end{frame}

\begin{frame}
    Para poder ampliar la variedad de problemas los que puede aplicarse nuestro modelo de Perceptrón Simple, vamos a suponer que el impulso que transmiten las neuronas no es necesariamente binario.

    \vspace{1cm}
    \pause

\end{frame}

\begin{frame}
    \begin{center}
    {\Large Entrenando a la red}
        
    \end{center}
    
    Como en todos los modelos de aprendizaje supervisado, queremos minimizar la discrepancia (medida por la función de pérdida) que existe entre lo que devuelve el modelo y el dato real.

    \vspace{1cm}
    \pause
    Si vamos a minimizar una función, ¿qué algoritmo podemos usar?

    \pause
    \vspace{1cm}
    \centering
    {\Large \emoji{sparkles} Descenso por Gradiente Estocástico \emoji{sparkles}}
\end{frame}

\begin{frame}
    El entrenamiento consiste en ir ajustando los pesos y el bias para minimizar la función de pérdida.

    \vspace{1cm}
    \begin{enumerate}
        \item Inicializá los pesos y el bias aleatoriamente
        \item En cada época:
        \begin{enumerate}
            \item Para cada dato $x^{(i)}$:
                \begin{enumerate}
                    \item \textit{Feedforward}: alimentamos a la red con $x^{(i)}$ como input, obtenemos $\hat{y}^{(i)}$ como output
                    \item \textit{Corrección}: medimos el error entre $y^{(i)}$ y $\hat{y}^{(i)}$, ajustamos los pesos
para disminuirlo
                \end{enumerate}
            \item mezclá el dataset
            
        \end{enumerate}
    \end{enumerate}
\end{frame}

\section{Clasificando pingüinos}

\begin{frame}
    Vamos a entrenar un perceptrón para predecir el sexo de un pingüino a partir de cuatro características:
    \begin{itemize}
        \item peso ($X_1$)
        \item longitud de aleta ($X_2$)
        \item longitud de pico ($X_3$)
        \item profundidad del pico ($X_4$)
    \end{itemize}

    \vspace{0.5cm}
    \pause
    \begin{columns}
        \begin{column}{0.5\textwidth}
        \blacktriangleright Arquitectura de la red neuronal:
        \begin{itemize}
            \item Neuronas en la capa de Input: \onslide<3->{4}
            \item Neuronas en la capa de Output: \onslide<4->{1}
            \item Función de activación: \onslide<5->{Sigmoidea}
            \item Función de pérdida ($L$): \onslide<6->{\small Binary Cross Entropy}
        \end{itemize}            
        \end{column}
        \begin{column}{0.5\textwidth}
        \onslide<7->{\blacktriangleright Codificación $y$:
        \[\text{\textit{Female:} } 1 \qquad \text{\textit{Male:} } 0\]}
        \onslide<8->{\blacktriangleright Inicialización aleatoria de $w$ y $b$}
        \onslide<9->{\blacktriangleright $\eta_k = 0.1$ constante}
        \end{column}
    \end{columns}
\end{frame}

\begin{frame}
    \begin{center}
        Para quien desee seguir las cuentas
    \end{center}
    \[w = (w_1, \dots, w_m)\]
    \[f_i(b,w) = \dfrac{1}{1 + e^{-(b + w^tx^{(i)})}} \qquad \text{vale que: } f^\prime (x)=f(x)(1-f(x))\]

    Función de error \textit{Binary Cross-Entropy Loss} o \textit{log loss} para Regresión Logística:
    \[L(b,w) = {\frac {1}{n}}\sum _{i=1}^{n}\ \underbrace{-{\bigg (}y^{(i)}\log (f_i(b,w))+(1-y^{(i)})\log(1-f_i(b,w)) \bigg)}_{F_i(b,w_1,\dots, w_m)}\]
    Tenemos que:
    \[    
    \begin{array}{l}
         \dfrac{\partial F_i}{\partial w_j}(b, w_1,\dots,w_m) = w_j(f_i(b,w_1,\dots,w_m)-y_i)  \\
          \dfrac{\partial F_i}{\partial b}(b, w_1,\dots,w_m) = -(f_i(b,w_1,\dots,w_m)-y_i)
    \end{array}
    \]
    

\end{frame}

Existen muchos teoremas de aproximación universal, que demuestran que existen redes neuronales que convergen a
ciertas clases de funciones.

\vspace{1cm}
Por ejemplo, el Teorema de Funahashi:

Sean $K\subset\mathbb{R}^n$ compacto, $f\colon K\rightarrow \mathbb{R}$ continua y $\varepsilon >0$, entonces existe
$g$ una red neuronal de dos capas tal que $\Vert f - g\Vert_{\infty}<\varepsilon$
